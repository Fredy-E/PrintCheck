PrintCheck

Experimental concept prototype — idea exploration only. This is a work-in-progress demo, not a finished or production-ready product.

A local evidence viewer for Windows printer queue, driver, and port metadata collected by collector/Collect-PrintCheck.ps1. It is not a compatibility certificate: print success, scan success, Windows protected print mode state, Mopria certification, and IPP/eSCL capability are never tested here and stay unknown.

Sample data — fictional. Not collected from a real computer.

      08 Limitations of every report

        PrintCheck runs entirely in this page from local files. It makes no network requests, keeps no persistent storage, and never reads print jobs. Built-in samples are fictional demo data.
